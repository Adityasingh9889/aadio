# aadio

> A clean starter repository for experiments, prototypes, and small automation projects.

## Overview

This repository is currently a lightweight project workspace. It is intentionally kept minimal so that future code can be organized around a clear project purpose rather than accumulating unrelated files.

## Focus Areas

- Cloud & infrastructure
- Networking and Linux
- Automation
- AI-assisted tools
- Practical developer experiments

## Repository Standards

Future additions should include:

- A clear project structure
- A useful README with setup instructions
- No secrets, tokens, credentials, or local runtime databases
- Reproducible setup steps
- Small, focused commits
